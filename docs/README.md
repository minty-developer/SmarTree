# SmarTree
> 폴더 종합 도우미 Windows 애플리케이션

## 1. 프로젝트 개요

### 1.1 프로젝트 목적

사용자의 파일과 폴더 구조를 분석하여 파일을 효율적으로 정리할 수 있도록 도와주는 서비스 제공

### 1.2 주요 사용자

- 파일과 폴더가 자주 뒤섞이는 사용자
- 다운로드 폴더 등을 주기적으로 정리하기 어려운 사용자
- 자신만의 파일 관리 구조를 만들고 싶은 사용자
- 많은 파일을 효율적으로 관리하고 싶은 사용자

### 1.3 기술 스택

- C# (.NET) WPF

### 1.4 Feature

- 폴더 매칭
- 파일 확장자 확인 후 분류
- 파일 제목으로 폴더 위치 제안
- 폴더 구조 제안
- 유사 파일 & 중복 파일 탐지 및 그룹화
- 오래된 파일 또는 임시 파일 탐지
- 압축 해제 시 압축 파일 삭제 제안
- 폴더 상태 분석
- Tag 검색
- 정리 결과 미리보기
- 선택한 제안만 적용
- 정리 규칙 사용자 지정
- 분석 결과 필터링
- 특정 파일/폴더 제외
- 자동 정리하지 않을 파일 지정
- 태그 추가/수정/삭제
- 정리 전후 상태 비교
