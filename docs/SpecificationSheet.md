## 1. 프로젝트 개요

### 1.1 프로젝트명

SmarTree

### 1.2 프로젝트 목적

사용자의 파일과 폴더 구조를 분석하여 파일을 효율적으로 정리할 수 있도록 도와주는 Windows 애플리케이션을 개발한다.

사용자가 직접 폴더 구조를 지정하거나 제공되는 폴더 구조 템플릿을 선택할 수 있으며, 이후 파일 상태를 점검하여 중복 파일, 유사 파일, 오래된 파일, 임시 파일 등의 정리 대상을 찾아 사용자에게 정리 방법을 제안한다.

### 1.3 주요 사용자

- 파일과 폴더가 자주 뒤섞이는 사용자
    
- 다운로드 폴더 등을 주기적으로 정리하기 어려운 사용자
    
- 자신만의 파일 관리 구조를 만들고 싶은 사용자
    
- 많은 파일을 효율적으로 관리하고 싶은 사용자
    

---

# 2. 초기 폴더 설정

사용자는 프로그램을 처음 실행했을 때 두 가지 방법 중 하나를 선택하여 관리할 폴더 구조를 설정한다.

## 2.1 폴더 매칭

사용자가 이미 만들어 둔 폴더 구조를 프로그램에 등록하는 기능이다.

### 기능

1. 관리할 기존 폴더를 선택한다.
    
2. 사용자가 폴더의 용도를 지정한다.
    
3. 다운로드 폴더 등의 외부 폴더를 지정한 폴더와 연결한다.
    
4. 프로그램이 해당 폴더 구조를 관리 대상으로 등록한다.
    

### 예시

```text
Downloads
    ↓
D:\2Projects\Archive

Documents
    ↓
D:\2Projects\Documents
```

사용자가 직접 구축한 폴더 구조를 그대로 활용할 수 있다.

---

## 2.2 폴더 구조 제안

새로운 폴더 구조가 필요한 사용자를 위해 미리 구성된 템플릿을 제공한다.

### 기능

1. 제공되는 폴더 구조 템플릿을 확인한다.
    
2. 원하는 템플릿을 선택한다.
    
3. 선택한 구조를 지정된 위치에 생성한다.
    
4. 생성된 폴더를 관리 대상으로 등록한다.
    

### 예시

```text
[개발자용]

Projects/
Resources/
Archive/
Documents/
Images/
```

템플릿 선택 후 해당 구조를 실제 폴더로 생성한다.

---

# 3. 기본 폴더 점검

등록된 폴더를 대상으로 파일과 폴더의 상태를 분석한다.

기본 점검은 사용자가 원하는 경우에만 실행할 수 있다.

### 검사 항목

- 파일 확장자 분석
    
- 파일명 분석
    
- 폴더 구조 분석
    
- 중복 파일 검사
    
- 유사 파일 검사
    
- 오래된 파일 검사
    
- 임시 파일 검사
    
- 압축 파일 검사
    
- 빈 폴더 검사
    

### 결과

점검 결과를 사용자에게 제공하여 현재 폴더의 문제점을 확인할 수 있도록 한다.

예:

```text
총 파일: 1,248개
총 폴더: 183개

중복 파일: 12개
유사 파일: 31개
임시 파일: 18개
오래된 파일: 47개
압축 파일: 23개
빈 폴더: 7개
```

---

# 4. 파일 분류 및 폴더 매칭

파일의 정보를 분석하여 적절한 폴더를 찾거나 사용자에게 이동 위치를 제안한다.

### 분석 기준

- 파일 확장자
    
- 파일명
    
- 현재 파일 위치
    
- 파일이 속한 폴더
    
- 다른 파일과의 관계
    

### 기능

- 확장자에 따른 파일 분류
    
- 파일명 기반 분류
    
- 기존 폴더와의 연관성 분석
    
- 적절한 폴더 위치 제안
    

---

# 5. 파일 관계 분석

파일 간의 관계를 분석하여 함께 관리할 수 있는 파일을 찾는다.

## 5.1 유사 파일 탐지

파일명 또는 파일의 특성을 비교하여 서로 관련성이 높은 파일을 탐지한다.

예:

```text
server.cs
server_old.cs
server_backup.cs
server_final.cs
```

위와 같은 파일을 하나의 그룹으로 제안할 수 있다.

## 5.2 중복 파일 탐지

동일한 파일이 여러 위치에 존재하는지 확인한다.

중복 파일을 그룹으로 표시하여 사용자가 불필요한 파일을 확인할 수 있도록 한다.

---

# 6. 불필요 파일 탐지

정리 대상이 될 가능성이 높은 파일을 탐지한다.

### 검사 대상

- 오래된 파일
    
- 임시 파일
    
- 백업 파일
    
- 빈 폴더
    
- 사용되지 않는 것으로 판단되는 파일
    

프로그램은 해당 파일을 자동으로 삭제하지 않고 사용자에게 정리 대상으로 제안한다.

---

# 7. 압축 파일 관리

압축 파일과 압축 해제된 폴더의 관계를 확인하여 불필요한 압축 파일을 탐지한다.

예:

```text
project.zip
project/
```

압축 파일이 이미 압축 해제된 것으로 판단되는 경우 사용자에게 원본 압축 파일의 삭제 또는 보관 여부를 제안한다.

---

# 8. 폴더 구조 분석 및 제안

현재 폴더 구조를 분석하여 개선할 수 있는 구조를 제안한다.

### 기능

- 파일이 과도하게 집중된 폴더 탐지
    
- 관련 파일이 여러 위치에 분산되어 있는지 확인
    
- 불필요한 폴더 탐지
    
- 새로운 폴더 생성 제안
    
- 파일 이동 위치 제안
    

사용자는 제안된 구조를 확인한 후 필요한 항목만 적용할 수 있다.

---

# 9. 폴더 상태 분석

관리 중인 폴더의 전체적인 상태를 확인할 수 있다.

### 제공 정보

- 전체 파일 수
    
- 전체 폴더 수
    
- 파일 종류별 개수
    
- 폴더별 파일 수
    
- 폴더 용량
    
- 중복 파일 수
    
- 정리 대상 파일 수
    
- 기타 분석 결과
    

이를 통해 사용자가 현재 폴더의 상태를 한눈에 확인할 수 있도록 한다.

---

# 10. Tag 기능

파일 및 폴더에 Tag를 지정하여 분류하고 검색할 수 있도록 한다.

### 기능

- Tag 생성
    
- Tag 지정
    
- Tag 수정
    
- Tag 삭제
    
- Tag 기반 검색
    

예:

```text
#CSharp
#Server
#Game
#Archive
```

`#Server`를 검색하면 해당 Tag가 지정된 파일 및 폴더를 확인할 수 있다.

---

# 11. 정리 제안

파일 분석 결과를 기반으로 사용자가 수행할 수 있는 정리 작업을 제안한다.

### 제안 항목

- 파일 이동
    
- 폴더 생성
    
- 파일 그룹화
    
- 중복 파일 정리
    
- 오래된 파일 정리
    
- 임시 파일 정리
    
- 압축 파일 삭제 또는 보관
    

프로그램은 사용자의 승인 없이 파일을 임의로 삭제하거나 이동하지 않는다.
